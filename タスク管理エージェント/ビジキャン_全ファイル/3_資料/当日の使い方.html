審査アプリ　当日の使い方（運営用）

「はじめに」→ 審査アプリ を開きます。ブラウザは Chrome か Safari。ネットは不要です。

📘 やり方（スライド）：アプリの「📘 やり方」タブに、各ステップの説明と、AIへの聞き方（コピーできる）が入っています。子どもに見せながら進めてください。

0. 始める前（開始の前日までに）

  1. アプリを開いて、📖 ルールと📅 予定のタブが出るか確認。
  2. 音が出るか確認（右上の 🔊）。会場のスピーカーにつなぐ。
  3. 「サンプル」ボタンで、1回通して動かしてみる。そのあと「全部リセット」で空にする。
  4. 収支タブの「結果を出すたびに自動で保存ファイルをダウンロード」がオンのまま（初期設定）にしておく。

1. 最初にやること（参加者の入力）

  1. ✏️ 入力タブで、「名前」と「行き先」を入れる（じゃんけんで決めた県）。
  2. 同じ県が選ばれると、赤い警告が出ます。直してください。
  3. 1人2つ作るときは、名前の下の「＋ 2本目のツアーを作る」を押す。
  4. 設定（折りたたみの中）の「最初の元手」は 150 のまま。

2. 1回ごとの進め方（6回）

回入力する列（色がつく）タイミング
1回目行き先行き先を選んだあと
2回目宿、値段宿を選んだあと
3回目タイトル作ったあと
4回目観光スポット1〜3旅行スケジュールを作ったあと
5回目広告（出す人だけチェック。画像があれば貼る）ミニ発表のとき
6回目全部の見直し2日目の最終ピッチ
  1. 入力が終わったら、左下の ▶ ペルソナ100人に見せる を押す。
  2. 集計の演出 → 3・2・1 → 広場でお客さんが走る → 自動で結果の画面 → 🏆 ランキングを見る。
  3. 時間がないときは、集計の画面の右下の「スキップ ▶」を押す。
  4. 結果の画面の「見る」で、お客さんの声（買った理由）が見られます。子どもに読んでもらうと盛り上がります。
  5. 終わったら、上の「次へ進む」を押して、次の回へ。

3. サイコロ・ルーレット・お金の手入力

  • 🎲 サイコロタブ：振る人を選んで「サイコロを振る」。3はチャンスカード、4はAI審査員の結果を、ボタンで入れる。お金は自動で反映。
  • 団体客ルーレット：同じタブの上。団体客の人数は 20 人（変えられる）。ツアーが2つの人は、2つのうち1つが、ランダムに当たる。回数は計4回（1日目1回、2日目3回）。
  • 💰 収支タブの「手入力」：賞金、ペナルティ、友だちが買った分（お客さんコイン50万円まで）を入れる。
  • 2日目の最終ピッチのあとに、友だちが買った分を「友だちが買った」で全員ぶん入れる。

4. 保存（かならず）

  • 結果を出すたびに、「ビジキャン保存_日付_自動.json」が、ダウンロードに入ります。消さないでください。
  • 収支タブの「いまの状態を保存（ファイル）」でも保存できます。
  • パソコンが止まったら：アプリを開き直して、収支タブの「保存したファイルを読み込む」で、いちばん新しいファイルを選ぶ。
  • スプレッドシートに残すなら、収支タブの「Googleスプレッドシートに貼る用にコピー」を押して、スプレッドシートのA2に貼る。

5. こまったとき

  • 結果が出ない／画面が動かない：ページを再読み込み（F5）。入力はブラウザの中に残っています。
  • 前の回の入力を直した：その回に戻って、もう一度「見せる」を押す（お金が計算し直される）。後ろの回も押し直す。
  • 音が出ない：右上の 🔊 を押して、「音あり」にする。会場のブラウザの音量も確認。
  • 全部消えた：保存ファイルを読み込む。
  • 別のブラウザや別のパソコンで開くと、入力は引き継がれません（保存ファイルで引き継ぐ）。
